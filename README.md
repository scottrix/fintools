# FinTools

Free online financial calculators — currency, mortgage, tax, investment & more. All client-side, fast & private.

## Calculators

| Category | Calculators |
|----------|-------------|
| **Currency** | Currency Converter, Crypto Converter, Historical Exchange Rates |
| **Mortgage** | Mortgage Calculator, Rent vs Buy, Stamp Duty (UK), Affordability |
| **UK Tax** | Income Tax, Self-Employed Tax, Dividend Tax, Capital Gains Tax, IR35, VAT |
| **US Tax** | Income Tax, Self-Employment Tax, Capital Gains Tax, State Tax Comparison |
| **Investment** | Compound Interest, FIRE Calculator, Investment Fee Analyzer, Dividend Reinvestment, ROI |
| **Salary** | Salary Converter, Hourly/Salary, Remote Salary Adjuster, Paycheck, Contractor Rate |
| **Loans** | Loan Calculator, Debt Payoff Strategy, Debt-to-Income Ratio, BNPL Comparison, APR |
| **Inflation** | Inflation Calculator, Personal Inflation Rate, Purchasing Power |
| **Retirement** | Retirement Calculator, Pension Calculator (UK), 401k Calculator, Social Security |
| **Business** | Break-Even Calculator, Profit Margin, Cash Flow Projector, Invoice Calculator |

## Features

- **100% client-side** — no financial data leaves your browser
- **UK & US support** — tax calculators for both countries
- **Dark/light mode** — respects system preference
- **Mobile responsive** — works on all devices
- **No login required** — no accounts, no tracking
